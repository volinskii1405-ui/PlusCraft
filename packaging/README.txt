PlusCraft — воксельная песочница (Rust + Vulkan)
================================================

Сборка: ЭТАП 8 — мир (биомы, пещеры, руды, шахты), физика, добыча,
освещение и сутки, инвентарь/крафт/печь, мобы с ИИ + уникальные механики:

 1. ОБВАЛЫ. После добычи блока порода свода без опоры может обрушиться
    (предупреждение «Свод неустойчив!» и 1.5–3.5 с на реакцию). Крепь
    (доски+палки, 4 шт.) в радиусе 4 блоков удерживает свод. Узкие туннели
    безопасны.
 2. РЕЗОНИТ. Светящаяся руда. Добыча рядом с ней вызывает эхо-импульс:
    7 с сквозь породу видны пустоты, руды, вода и лава. Резонатор (осколок
    резонита + медный слиток + палка) делает импульс по ПКМ. Эхо приманивает
    враждебных мобов.
 3. СВЕТ — РЕСУРС. Факелы выгорают (12 мин по умолчанию). ПКМ углём по
    факелу — дозаправка, по прогоревшему — зажечь. В полной тьме через 4 с
    наступает страх темноты (замедление, голод). Мракоед живёт только во
    тьме и гасит факелы.
 4. ВОДА. Течёт по уровням, падает, заливает шахты. Под землёй встречаются
    затопленные полости; столб воды 3+ блока размывает соседние землю,
    песок, гравий, глину. Ведро зачерпывает/выливает воду.
 5. МУТАЦИИ. Мобы, рождённые глубже (y<42/26/12), сильнее, быстрее,
    крупнее и с фиолетовым оттенком.

Мобы: Луговик и Кабан (мирные), Ползун (горит на солнце), Пещерный паук,
Мракоед (враждебные).
48 рецептов + 15 плавок — в assets/data/recipes.ron.

Начало игры в выживании: добудьте рукой бревно (ЛКМ по стволу), сделайте
доски (бревно в сетку 2×2), из 4 досок — верстак, поставьте его и
откройте ПКМ. Дальше — палки, деревянная кирка, камень, печь, факелы.

Запуск
------
    ./pluscraft

Требования: Linux x86_64, драйвер Vulkan 1.1+ (Mesa RADV/ANV/lavapipe,
NVIDIA proprietary и т.п.), X11 или Wayland.
Если Vulkan не найден, игра сообщит об ошибке в терминале.

Управление (этап 8)
-------------------
    ЛКМ (клик)     — захватить мышь
    Мышь           — обзор
    W A S D        — ходьба
    Пробел         — прыжок / всплыть
    Shift          — присесть (не упадёте с края)
    Ctrl           — бег
    ЛКМ (удерж.)   — ломать блок; ЛКМ по мобу — удар (в прыжке — критический)
    ПКМ            — поставить блок / съесть еду / открыть верстак, печь,
                     сундук (с Shift — поставить блок рядом) / резонатор /
                     ведро / уголь по факелу
    E              — инвентарь (Esc или E — закрыть)
    СКМ            — выбрать блок
    1..9, колесо   — слот хотбара
    Q / Ctrl+Q     — выбросить предмет / весь стак
    F3             — отладочная информация
    F6             — переключить режим (выживание / креатив) [отладка]
    F (креатив)    — полёт; двойной пробел — тоже полёт
    T              — консоль команд (Enter — выполнить, Esc — закрыть)
    Esc            — отпустить мышь
Клавиши переназначаются в settings.toml ([controls.bindings]).

Инвентарь
---------
    ЛКМ по слоту       — взять / положить / поменять стак
    ПКМ по слоту       — взять половину / положить один предмет
    Shift+ЛКМ          — быстро переложить (инвентарь <-> контейнер,
                         хотбар <-> рюкзак); по результату крафта — скрафтить
                         всё, что возможно
    клик вне окна      — выбросить предмет с курсора
    В креативе вместо сетки 2×2 — палитра всех предметов (колесо — прокрутка,
    клик по палитре с предметом на курсоре — удалить его).

Команды консоли
---------------
    /time day|noon|sunset|night|midnight|0..1   — время суток
    /gamemode s|c                               — выживание / креатив
    /tp x y z                                   — телепорт
    /give предмет [n]                           — выдать (ключи: torch, planks,
                                                  stone_pickaxe, coal ...)
    /setblock x y z блок                        — поставить блок
    /fill x1 y1 z1 x2 y2 z2 блок                — заполнить область (air — воздух)
    /summon grazer|boar|crawler|spider|gloom [мутация 0..3] [x y z]
    /pulse [радиус]                             — эхо-импульс резонанса
    /findcave                                   — в ближайшую пещеру (отладка)
    /ui crafting|furnace|chest                  — поставить и открыть (отладка)
    /heal, /kill, /seed, /help

Seed мира: --seed ЧИСЛО_ИЛИ_СТРОКА или gameplay.default_seed в settings.toml.
Дальность прорисовки: graphics.render_distance в settings.toml (2..16).

Файлы
-----
    pluscraft                 — исполняемый файл
    settings.toml             — настройки (FOV, VSync, чувствительность, клавиши...)
    assets/shaders/*.spv      — скомпилированные шейдеры (SPIR-V)
    assets/textures/blocks.png— атлас текстур (можно перерисовать)
    assets/fonts/             — шрифт интерфейса (DejaVu Sans) и его лицензия

Параметры командной строки
--------------------------
    --gen-assets       перегенерировать атлас текстур и settings.toml
    --seed S           seed мира (число или строка)
    --exit-after N     выйти через N секунд (для тестов)
    --cmd "/команда"   выполнить команду после загрузки мира (можно несколько;
                       "@5 /команда" — через 5 с после старта)
    --selftest         автоматическая проверка механик (физика, добыча,
                       подбор, установка, урон от падения, пересчёт света, печь, сундук, атака моба, смерть
                       и дроп моба, ночной спавн, обвал, крепь, резонанс,
                       вода, страх темноты, выгорание факела); код выхода 0 = ОК

Логи: переменная RUST_LOG=debug включает подробный вывод.
